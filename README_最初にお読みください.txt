【既存環境への適用】
1. アプリを終了します。
2. アプリの設置フォルダ名を ZCS_Polaroid_Maker に統一することを推奨します。
3. v1.8のapp.pyを設置フォルダへ上書きします。
4. start_windows.batを起動します。

依存パッケージは変更していないため、通常は再セットアップ不要です。
